# Linear Regression from Scratch Using Python

## Project Overview

This project demonstrates the implementation of
Linear Regression using Core Python without
external Machine Learning libraries.

## Objective

To understand the mathematical foundation of
Linear Regression and predict output values
using input data.

## Technologies Used

- Python
- Core Python Programming

## Mathematical Formula

y = mx + c

Where:
- m = Slope
- c = Intercept
- x = Input variable
- y = Predicted output

## Features

- Custom summation function
- Slope calculation
- Intercept calculation
- Prediction of output values

## Sample Dataset

| X | Y |
|---|---|
| 20 | 100 |
| 22 | 110 |
| 24 | 120 |
| 26 | 130 |
